# Simulador Sweet Village

Simulador de proposta do Sweet Village (VPA Urbanismo) pela Tabela Price.

O site é publicado pelo GitHub Pages a partir do arquivo `index.html` na branch `main`. Esse arquivo é gerado por `build.py` a partir de `src/simulador.html`, que também é a fonte do artefato usado pelos corretores no claude.ai.

Simulação meramente ilustrativa, sem valor de proposta, oferta ou reserva, que não gera qualquer compromisso da VPA Urbanismo.
